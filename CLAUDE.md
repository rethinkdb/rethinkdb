# RethinkDB Maintenance Guide (Claude)

This repository is a fork of RethinkDB being maintained for research and optimization.

## Build Commands
- Configure: `./configure --allow-fetch`
- Build: `make`
- Test: `make test`

## Coding Style
- Follow standard C++11/14 conventions.
- Use the Google C++ Style Guide where applicable for new modules.
- Ensure all distributed logic is documented in `/docs`.
